# Памятка оператора бота

## Панель статистики в браузере

- `/dashboard` — новые одноразовая ссылка и пароль, сессия и удалённый доступ на 10 минут с момента запроса. Новый запрос отзывает предыдущий доступ.
- `/dashboard local` — ссылка для домашней сети без запуска внешнего туннеля.
- `/dashboard close` или «Закрыть доступ» — отозвать все ссылки и сессии.

Команда доступна только владельцу в личном чате. Ссылка и отдельный пароль действуют десять
минут с момента запроса и используются один раз. Новый запрос отзывает старые ссылки
и сессии. Пароль вводится на странице и не содержится в URL. После
входа ключ исчезает из адреса, сессия хранится в HttpOnly cookie. В базе остаются
только хэши ключей. Через интернет используется временный HTTPS-туннель
Cloudflare; он закрывается по таймеру. Наличие адреса сайта не даёт доступ к данным.
Локальный адрес задаётся `DASHBOARD_LOCAL_URL` в приватном `.env`. Сервис
`scripts/stats-tunnel.service` запускает туннель по запросу; бот не получает Docker socket.

Панель показывает регистрации, пользователей с любым действием кроме `/start`,
пользователей с конвертациями, результаты, объём отправок, площадки и журнал.
Есть периоды и произвольные даты, поиск пользователя, фильтры площадки, результата,
формата, действия и исхода, а также пагинация. По умолчанию владелец исключён из
аудитории; системные события остаются видимыми. Старые `/stats`, `/analytics`
и выгрузки сохраняются.

Журнал действий хранится 90 дней и не содержит текстов сообщений, адресов
скачиваемых публикаций и значений callback. История конвертаций хранится отдельно;
старые записи могут не содержать площадку и формат. Системные запуски и штатные
остановки начинают фиксироваться с установки панели; аварийная остановка без
корректного завершения не может оставить событие остановки.

Команды оператора доступны только аккаунту `ADMIN_ID`. Для аналитики используйте личный чат с ботом.

## Диалоги с пользователями

Пользователь пишет `/contact`, затем отправляет текст, фото или файл. Бот пересылает их в операторскую предложку. Ответьте **на служебную карточку или пересланное сообщение** в этой предложке: бот доставит ответ нужному пользователю. Пользователь завершает диалог командой `/end`; после этого ссылки снова обрабатываются как загрузки.

- `/users` — последние пользователи; `/users username` — поиск по username или ID.
- `/tell ID текст` или `/tell @username текст` — написать пользователю, уже запускавшему бота.
- `/tell ID` ответом на готовое сообщение — переслать это сообщение пользователю.
- `/suggestions` — очередь идей и запросов на новые сервисы.
- `/reply НОМЕР текст` — ответить на конкретное предложение.

Не используйте `/tell` для массовых объявлений: для них есть подтверждаемая рассылка.

## Объявления и канал

`/post текст` публикует новость в канале. Ответьте `/post` на готовое сообщение, чтобы сохранить оформление и вложение. Пользователю подписка на канал не нужна для работы бота.

Рассылка через бот начинается только после подтверждения:

1. Подготовьте сообщение с нужным текстом, фото или файлом в приватной группе **TikTokDownloaderFF — рассылки**. Ответьте на него командой `/broadcast`.
2. Проверьте предпросмотр, число получателей и нажмите **«Отправить всем»**. До нажатия создаётся только черновик. Кнопка **«Отменить»** отменяет черновик.
3. `/broadcasts` показывает последние рассылки и позволяет остановить текущую. Отправка идёт не быстрее одного сообщения в секунду; пользовательские ответы и загрузки имеют приоритет.

Получатели берутся из пользователей, которые запускали бота. Заблокировавшим бота аккаунтам Telegram не позволяет доставлять сообщения; они исключаются из следующих рассылок. Статус «доставка не подтверждена» означает, что Telegram не подтвердил результат сетевого запроса: бот не повторяет такое сообщение автоматически, чтобы избежать дубля.

## Статистика и диагностика

- `/analytics`, `/analytics 7d`, `/analytics 30d` — активные, новые и вернувшиеся пользователи, итоги по сервисам, действия и время отправки файлов.
- `/analytics_export 7d` или `30d` — ограниченный CSV с событиями, загрузками и отправками. Текст сообщений и данные кнопок в него не входят.
- `/stats` — краткая статистика; `/events` — частые действия за сутки.
- `/control` — настройки и состояние маршрутов. Если включён резерв WARP, доступность выхода не подтверждает здоровье собственных VPN-узлов.

Для неисправной ссылки попросите пользователя прислать саму ссылку через `/contact`, чтобы видеть конкретный пример и ответить в той же цепочке.
